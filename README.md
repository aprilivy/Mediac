# Mediac

A Minecraft mod that enables the control of media from within Minecraft, through the operating systems media API, as of now it only supports Windows (although Linux & MacOS support will come in the future)

it only supports Minecraft 26.2 and requires the [Fabric API](https://modrinth.com/mod/fabric-api) to use

---

If you're using Spotify, you may need to go into your prefs and switch  `ui.system_media_controls_enabled=false` to `ui.system_media_controls_enabled=true`
